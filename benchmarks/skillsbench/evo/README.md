# Evolution adapters

Use `segos signals` and `segos evolve` from the repository entry point.
The core pipeline computes condition-specific updates in topology → weights →
descriptions order. Selected per-task trials feed the ordinary update channels;
raw attempts preserve actual co-use for avoid evidence. Training task filters
apply inside update functions. Avoid support never merges skills across attempts.

Caches bind inputs, selected tasks, model, policy version and retrieval budgets.
L3 checks the net added-token cap with the bundled cl100k_base vocabulary and
checks the combined output's no-eviction constraint. Existing published graphs
and rewards are not rewritten by evolving a new graph.
